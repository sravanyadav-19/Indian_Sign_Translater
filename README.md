# 🤟 ISL Learning Hub — Indian Sign Language Translator

Real-time **Indian Sign Language (ISL)** translator + learning hub. A webcam
frame is sent to a trained **CNN** that predicts the sign being shown
(**Sign → Text**), and typing a word plays the matching sign video
(**Text → Sign**).

Built with an Express/Node backend that shells out to a TensorFlow/Keras model
in Python, plus a glassmorphism single-page UI (light/dark mode).

## ✨ Features
- 🎥 **Live Sign → Text detection** — webcam frames classified by a CNN (64×64 grayscale).
- 🔤 **Text → Sign playback** — type a word to see its sign video.
- 📒 **Detection log** — predicted signs with timestamps, click to replay.
- 🌗 Dark / light theme, animated gradient background.
- 🧰 Data-collection + training scripts to build your own model.

## 🗂️ Structure
```
backend/
├── server.js            # Express API (POST /predict) + static serving
├── package.json
├── requirements.txt     # Python deps (tensorflow, opencv, flask-cors...)
├── Dockerfile
└── ai/
    ├── isl_predict.py        # loads model, classifies a single frame
    ├── train_model.py        # trains the CNN from dataset/*.jpg
    ├── collect_my_signs.py   # capture your own signs from the webcam
    ├── collect_frames.py     # extract frames from sign videos
    └── dataset/              # <sign>_<...>.jpg training images
frontend/
└── index.html           # the whole UI
```

## 🚀 Setup & run
1. **Backend deps**
   ```bash
   cd backend
   npm install
   pip install -r requirements.txt      # Python 3.10/3.11 recommended
   ```
2. **(Optional) collect & train a model** — `isl_model.h5` + `label_map.json`
   are generated by training and are **not** committed:
   ```bash
   cd ai
   python collect_my_signs.py   # change SIGN_WORD per word; capture 200 frames each
   python train_model.py        # writes isl_model.h5 + label_map.json
   ```
3. **Run the server**
   ```bash
   cd backend
   npm start                    # http://localhost:7240
   ```
   On Linux/Mac the server calls `python3`; set `PYTHON_BIN=python` on Windows.

4. Open **http://localhost:7240**, allow the webcam, and start signing.

## 📝 Notes
- Trained weights (`*.h5`), `label_map.json`, dataset images and sign videos
  are git-ignored (large, reproducible) — train locally or fetch from a release.
- Prediction only emits a label above an **0.85 confidence** threshold.
